
# 🔀 AutoMerge Web

Интерактивный веб-инструмент для трёхстороннего слияния (3-way merge) исходного кода с визуальным разрешением конфликтов.

## 📖 Описание

AutoMerge Web — это веб-приложение, которое имитирует процедуру автоматического слияния (automerge) в системах контроля версий (Git, SVN, Mercurial). 

Приложение принимает три версии файла:
- **Оригинал** — исходная версия файла
- **Версия 1** — изменения первого разработчика
- **Версия 2** — изменения второго разработчика

И автоматически объединяет изменения, разрешая конфликты в интерактивном режиме.

## ✨ Возможности

### 🎯 Основные функции
- **Автоматическое слияние** — алгоритм на основе LCS (Longest Common Subsequence) автоматически объединяет непересекающиеся изменения
- **Визуальное разрешение конфликтов** — интерактивный интерфейс для ручного разрешения конфликтующих изменений
- **Подсветка конфликтных строк** — номера строк с конфликтами выделяются красным цветом
- **Три режима разрешения конфликтов**:
  - ✓ Взять Версию 1 — использовать изменения только первого разработчика
  - ✓ Взять Версию 2 — использовать изменения только второго разработчика
  - 🔀 Комбинация — объединить оба варианта с цветовой подсветкой для ручного редактирования

### 🎨 Интерфейс
- **Номера строк** — как в GitLab/GitHub, с синхронизацией скролла между всеми полями
- **Автокопирование** — при вставке текста в поле "Оригинал", он автоматически копируется в поля версий (если они пусты)
- **Редактируемое поле результата** — поле "Merged" поддерживает прямое редактирование с сохранением форматирования
- **Цветовая подсветка** — синий цвет для Версии 1, фиолетовый для Версии 2 в режиме комбинации

### ️ Настройки
- **Игнорирование whitespace** — опция для игнорирования различий в пробелах и отступах при сравнении с оригиналом

1. **Клонируйте репозиторий:**

## 📋 Как использовать

### Пример 1: Простое слияние без конфликтов

1. Вставьте исходный код в поле **"Исходный файл (Original)"**
2. Внесите изменения в поле **"Версия 1"** (например, добавьте новую функцию)
3. Внесите изменения в поле **"Версия 2"** (например, измените другую часть кода)
4. Нажмите кнопку **"⚡ Выполнить слияние (Merge)"**
5. Результат появится в поле **"Результат слияния (Merged)"**

### Пример 2: Разрешение конфликтов

1. Создайте ситуацию, когда оба разработчика изменили одну и ту же строку по-разному
2. Нажмите **"Выполнить слияние"**
3. Внизу появится панель **"Неразрешённые конфликты"**
4. Для каждого конфликта выберите:
   - **"Взять Версию 1"** — использовать изменения первого разработчика
   - **"Взять Версию 2"** — использовать изменения второго разработчика
   - **"Комбинация"** — вставить оба варианта с цветовой подсветкой и отредактировать вручную

### Пример 3: Игнорирование whitespace

Если разработчики изменили только отступы (например, один использовал табы, другой пробелы):
1. Включите чекбокс **"Игнорировать различия в whitespace"**
2. Нажмите **"Выполнить слияние"**
3. Алгоритм не будет считать такие изменения конфликтом

## 🔧 Алгоритм работы

### Трёхстороннее слияние (3-way merge)

1. **Поиск LCS** — алгоритм находит наибольшую общую подпоследовательность (LCS) между оригиналом и каждой из версий
2. **Определение стабильных точек** — строки, которые совпали в обеих версиях, служат "якорями"
3. **Анализ регионов** — между стабильными точками анализируются изменения:
   - Если изменил только один разработчик → берём его изменения
   - Если оба изменили одинаково → берём изменение один раз
   - Если оба изменили по-разному → помечаем как конфликт
4. **Генерация результата** — формируется итоговый текст с маркерами конфликтов

### Формат маркеров конфликтов

```
<<<<<<< Конфликт (версия 1)
код из версии 1
=======
код из версии 2
>>>>>>> Конфликт (версия 2)
```

## 🎯 Примеры использования

### Сценарий 1: Добавление новых функций

**Оригинал:**
```python
def calculate(x, y):
    return x + y
```

**Версия 1** (добавил умножение):
```python
def calculate(x, y):
    return x + y

def multiply(x, y):
    return x * y
```

**Версия 2** (добавил вычитание):
```python
def calculate(x, y):
    return x + y

def subtract(x, y):
    return x - y
```

**Результат слияния:**
```python
def calculate(x, y):
    return x + y

def multiply(x, y):
    return x * y

def subtract(x, y):
    return x - y
```

### Сценарий 2: Конфликт изменений

**Оригинал:**
```python
MAX_RETRIES = 3
```

**Версия 1:**
```python
MAX_RETRIES = 5
```

**Версия 2:**
```python
MAX_RETRIES = 10
```

**Результат:** Конфликт → пользователь выбирает значение вручную

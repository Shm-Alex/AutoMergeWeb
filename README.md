## 📖 Описание

AutoMerge Web — это веб-приложение, которое имитирует процедуру автоматического слияния (automerge) в системах контроля версий (Git, SVN, Mercurial). 

Приложение принимает три версии файла:
- **Оригинал** — исходная версия файла.
- **Версия 1 (первый программист)** — изменения первого разработчика.
- **Версия 2 (второй программист)** — изменения второго разработчика.

Приложение автоматически объединяет непересекающиеся изменения и предоставляет интерактивный интерфейс для ручного разрешения конфликтов.

## ✨ Возможности

### 🎯 Основные функции
- **Автоматическое слияние** — алгоритм на основе LCS (Longest Common Subsequence) автоматически объединяет непересекающиеся изменения.
- **Интерактивное разрешение конфликтов** — удобная панель для ручного разбора конфликтующих участков кода.
- **Три режима разрешения конфликтов**:
  - ✓ **Взять Версию 1** — использовать изменения только первого разработчика.
  - ✓ **Взять Версию 2** — использовать изменения только второго разработчика.
  - 🔀 **Комбинация** — вставить оба варианта с цветовой подсветкой (синий/фиолетовый) для последующего ручного редактирования прямо в поле результата.
- **Игнорирование whitespace** — опция для игнорирования различий в пробелах и отступах при сравнении с оригиналом.

### 🎨 Интерфейс (UX/UI)
- **Синхронизированный скролл** — прокрутка любого из четырёх полей автоматически и пропорционально прокручивает все остальные поля.
- **Номера строк как в GitLab** — с визуальной подсветкой конфликтных строк.
- **Кнопка "+" на номерах строк** — при наведении на конфликтную строку появляется кнопка, клик по которой мгновенно прокручивает интерфейс к карточке этого конфликта.
- **Автокопирование** — при вставке текста в поле "Оригинал", он автоматически дублируется в поля версий (если они пусты).
- **Редактируемое поле результата** — поле "Merged" поддерживает прямое редактирование (contenteditable) с сохранением форматирования и цветовых маркеров.

## 🚀 Быстрый старт (Локальная разработка)

### Требования
- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) или новее.
- Любой современный браузер (Chrome, Firefox, Edge, Safari).

### Установка и запуск
1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Shm-Alex/AutoMergeWeb.git
   cd AutoMergeWeb
   ```
2. **Восстановите зависимости:**
   ```bash
   dotnet restore
   ```
3. **Запустите приложение:**
   ```bash
   dotnet run
   ```
4. **Откройте браузер:** Перейдите по адресу, указанному в консоли (обычно `http://localhost:5000` или `https://localhost:7253`).

## 🌐 Развёртывание на Linux-сервере (Production)

Проект оптимизирован для развёртывания на слабых VPS (например, с 1 ГБ RAM), где уже работают другие сервисы (VPN, Docker и т.д.).

**Особенности продакшен-деплоя:**
1. **Только Runtime**: На сервер устанавливается только `aspnetcore-runtime-9.0` (без тяжёлого SDK), что экономит место и память.
2. **Systemd сервис**: Приложение работает как фоновый сервис с жёстким лимитом памяти (`MemoryMax=150M`), что гарантирует безопасность других процессов на сервере.
3. **Автоматический деплой из Visual Studio**: В корне проекта лежит скрипт `Deploy.bat`. Один клик в меню Visual Studio (`Средства -> 🚀 Деплой на сервер`) выполняет:
   - Сборку проекта в режиме Release.
   - Мгновенную передачу файлов на сервер через `scp` (по SSH-ключам, без ввода пароля).
   - Автоматический перезапуск сервиса (`systemctl restart`).

*(Подробные инструкции по настройке сервера и SSH-ключей см. в разделе "Wiki" или в истории коммитов).*

## 📋 Как использовать

### Пример 1: Простое слияние без конфликтов
1. Вставьте исходный код в поле **"Исходный файл (Original)"**.
2. Внесите изменения в поле **"Версия 1"** (например, добавьте новую функцию).
3. Внесите изменения в поле **"Версия 2"** (например, измените другую часть кода).
4. Нажмите кнопку **"⚡ Выполнить слияние (Merge)"**.
5. Результат мгновенно появится в нижнем поле.

### Пример 2: Разрешение конфликтов
1. Создайте ситуацию, когда оба разработчика изменили одну и ту же строку по-разному.
2. Нажмите **"Выполнить слияние"**.
3. Номера конфликтных строк подсветятся красным, а внизу появится панель **"Неразрешённые конфликты"**.
4. Для каждого конфликта нажмите одну из кнопок:
   - **"Взять Версию 1"** или **"Взять Версию 2"**.
   - **"Комбинация"** — вставит оба варианта в поле результата, раскрасив их в разные цвета. Вы можете кликнуть прямо в поле результата и отредактировать итоговый код вручную.
5. После разрешения всех конфликтов поле результата подсветится зелёным.

## 🔧 Алгоритм работы

### Трёхстороннее слияние (3-way merge)
1. **Поиск LCS** — алгоритм находит наибольшую общую подпоследовательность (Longest Common Subsequence) между оригиналом и каждой из версий.
2. **Определение стабильных точек** — строки, которые совпали в обеих версиях, служат "якорями".
3. **Анализ регионов** — между стабильными точками анализируются изменения:
   - Если изменил только один разработчик → берём его изменения.
   - Если оба изменили одинаково → берём изменение один раз.
   - Если оба изменили по-разному → помечаем как конфликт.
4. **Генерация результата** — формируется итоговый текст с визуальными маркерами.

### Формат маркеров конфликтов
```text
<<<<<<< 🔴 КОНФЛИКТ: Версия 1
код из версии 1
=======
код из версии 2
>>>>>>> 🔵 КОНФЛИКТ: Версия 2
```

## 🛠 Технологии

- **Backend:** ASP.NET Core 9.0 MVC (C#).
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (без тяжёлых фреймворков для максимальной отзывчивости UI).
- **Алгоритм:** LCS (Longest Common Subsequence) через динамическое программирование (O(N·M)).
- **DevOps:** SSH, SCP, systemd, Bash/Batch scripting для автоматизации.

## 🎯 Примеры использования

### Сценарий 1: Добавление новых функций
**Оригинал:**
```python
def calculate(x, y):
    return x + y
```
**Версия 1:** (добавил умножение)
```python
def calculate(x, y):
    return x + y

def multiply(x, y):
    return x * y
```
**Версия 2:** (добавил вычитание)
```python
def calculate(x, y):
    return x + y

def subtract(x, y):
    return x - y
```
**Результат слияния:** (Объединит оба добавления автоматически)
```python
def calculate(x, y):
    return x + y

def multiply(x, y):
    return x * y

def subtract(x, y):
    return x - y
```
